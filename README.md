# AI Infra 工程师知识体系

一门以**推理基础设施（Inference Infrastructure）**为深入主线的中文工程课程。课程覆盖从计算机系统、分布式与 GPU，到模型计算、资源调度、训练、推理和平台成本的八个层次。当前版本是可迭代的**课程骨架**：章节给出学习目标、前置知识、关键概念、动手实验和验收标准，详细课文将逐步补齐。

在线阅读：[GitHub Pages 课程站](https://tanghuaizhe.github.io/ai-infra-course/)。

## 适合谁

已有 Python 或其他语言的开发经验，愿意通过实验理解大模型服务的性能、可靠性与成本的人。六个月路线按每周约 10–15 小时设计，是学习计划，不是掌握生产级大规模集群的保证。单机 CPU 可完成部分原理与模拟实验；真实 GPU 性能实验需要相应硬件或云资源。

## 学习主线

`系统与分布式基础 → GPU 与模型计算 → 单机推理 → 推理引擎性能 → 集群调度与服务治理 → 训练基础 → 平台与成本优化`

八层内容按依赖组织，实际工程问题会跨层出现。建议先读 [课程目录](docs/README.md)，按 [六个月路线](ROADMAP.md) 完成实验，并把测试条件、原始数据和分析写入学习记录。

## 课程使用方式

1. 阅读章节的前置知识与学习目标；未知概念先回到对应基础模块。
2. 完成动手实验，记录硬件、软件版本、输入负载和结果。无 GPU 时先做标明的模拟或分析任务。
3. 用章节验收标准自查；尚未给出实现细节的项目明确标记为待完善。
4. 在 [参考资料](docs/references.md) 中核对官方文档和项目仓库。工具行为随版本变化，应以实际运行版本为准。
