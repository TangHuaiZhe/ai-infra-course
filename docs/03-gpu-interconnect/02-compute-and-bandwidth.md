# 计算与带宽分析

本章面向需要判断算子“缺计算能力还是缺数据供给”的读者。完成后，你应能用算术强度和 Roofline（屋顶线性能模型）给出理论性能上限，并明确它不是运行时间预测器。

## 学习目标与前置知识

- 计算工作量、内存流量和算术强度。
- 计算屋顶线的转折点、性能上限和理想时间下界。
- 区分理论带宽、有效带宽和性能剖析结果。
- 先完成[GPU 架构与存储](01-gpu-architecture.md)和[Transformer 与注意力](../04-deep-learning-compute/02-transformer-and-attention.md)。

## 三个基础量

先为同一个计算范围定义以下量：

- 工作量 `W`：执行的浮点运算数，单位为 FLOP（浮点运算次数）。
- 内存流量 `Q`：在所分析存储层次实际读写的字节数。
- 算术强度 `I = W ÷ Q`：每移动一个字节完成多少次浮点运算，单位为 `FLOP/字节`。

同一个算子相对于高带宽显存、L2 缓存和共享内存可以有不同的算术强度，因为各层实际流量不同。估算时必须说明流量边界。

## 屋顶线模型

设设备在目标数据类型和运算上的峰值计算吞吐为 `P`，所分析内存层次的带宽为 `B`。简化屋顶线给出的性能上限是：

`性能上限 = min(P, B × I)`

计算上限和带宽上限的交点称为转折点：

`转折算术强度 = P ÷ B`

当 `I` 低于转折点时，简化模型把工作负载归入带宽受限区域；高于转折点时归入计算受限区域。NVIDIA Nsight Compute（英伟达内核性能分析工具）的[屋顶线说明](https://docs.nvidia.com/nsight-compute/ProfilingGuide/index.html#roofline-charts)同样以峰值性能、内存带宽和算术强度构造边界。

对应的理想时间下界可以写为：

`时间下界 = max(W ÷ P, Q ÷ B)`

它假设计算和内存供给能达到各自理想上限，并在较慢边界下完美重叠。实际程序还受指令依赖、占用率、缓存、分支、同步、内核启动、数据布局和频率变化影响，因此实际时间通常更长。

## 运行屋顶线估算实验

在仓库根目录运行：

```bash
python3 examples/roofline_estimator.py
```

默认教学假设如下：

- 工作量：`1 TFLOP`，即 `10¹²` 次浮点运算。
- 内存流量：`100 GB`。
- 峰值计算吞吐：`100 TFLOP/s`。
- 内存带宽：`2000 GB/s`。

因此：

- 算术强度为 `10 FLOP/字节`。
- 转折点为 `50 FLOP/字节`。
- 理想计算时间为 `10 ms`。
- 理想内存时间为 `50 ms`。
- 屋顶线下界为 `50 ms`，性能上限为 `20 TFLOP/s`，属于带宽受限区域。

这些硬件数字是为了得到易复算结果的假设值，不对应特定 GPU。

把内存流量改为 `10 GB`：

```bash
python3 examples/roofline_estimator.py --memory-gb 10
```

算术强度变为 `100 FLOP/字节`，理想内存时间降为 `5 ms`。此时计算时间 `10 ms` 更长，模型把工作负载归入计算受限区域，性能上限为 `100 TFLOP/s`。

## 从估算走向测量

使用真实设备时，按以下顺序记录：

1. 固定模型、输入形状、数据类型和软件版本。
2. 明确 FLOP 计算口径和内存流量层次。
3. 用设备事件或性能分析工具测量内核运行时间。
4. 用实际读写字节数除以时间计算有效带宽。
5. 将实测点与对应屋顶线比较，检查差距是否来自计算、内存或其他资源。

理论规格与实测有效带宽不应混在同一列。CUDA 最佳实践指南给出的有效带宽口径是“读字节数加写字节数，再除以运行时间”；详见[带宽计算说明](https://docs.nvidia.com/cuda/cuda-c-best-practices-guide/index.html#bandwidth)。

## 验收标准

- 能写出算术强度、屋顶线性能上限和时间下界三个公式。
- 能复现默认配置的 `10 FLOP/字节`、`20 TFLOP/s` 和 `50 ms`。
- 能解释把内存流量降到 `10 GB` 后为什么进入计算受限区域。
- 能说明同一算子相对于不同存储层次为何有不同算术强度。
- 能列出至少五项屋顶线模型没有覆盖的实际瓶颈。
